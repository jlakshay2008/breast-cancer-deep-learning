# Breast Cancer Classification using Deep Learning

## About the Project

This project uses Deep Learning to classify samples from the Breast Cancer dataset using a Neural Network.

## Dataset

The project uses the Breast Cancer dataset provided by Scikit-learn.

- Number of samples: 569
- Number of features: 30

## Technologies Used

- Python
- TensorFlow
- Keras
- Scikit-learn
- Google Colab
- Neural Network

## Deep Learning Model

The project uses a feed-forward Neural Network with:

- Input layer with 30 features
- Dense layer with 32 neurons and ReLU activation
- Dense layer with 16 neurons and ReLU activation
- Output layer with 1 neuron and Sigmoid activation

## Workflow

1. Load the dataset
2. Split the dataset into training and testing data
3. Standardize the features
4. Build the Neural Network
5. Train the model
6. Evaluate the model
7. Generate predictions

## Result

The trained Neural Network is evaluated on the test dataset using accuracy, classification report, and confusion matrix.
